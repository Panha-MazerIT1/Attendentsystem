# ប្រព័ន្ធគ្រប់គ្រងវត្តមាន — ណែនាំដំឡើង (ប្រហែល ១៥ នាទី)

File ទាំងអស់ក្នុង folder នេះ៖ `index.html` · `app.css` · `app.js` · `config.js` · `schema.sql`

## ក. បង្កើត database (Supabase)

1. ចូល **supabase.com** → ចុះឈ្មោះ → **New project**។ ជ្រើស Region ជិតបំផុត (ឧ. Singapore) ហើយកត់ទុកលេខសម្ងាត់ database។
2. ចូល **SQL Editor** → **New query** → បិទ (paste) មាតិកាទាំងអស់ពី `schema.sql` → ចុច **Run**។ ត្រូវឃើញ "Success"។
3. ចូល **Authentication → Users → Add user → Create new user**។ បញ្ចូលអ៊ីមែល និងលេខសម្ងាត់ដែលអ្នកនឹងប្រើចូលកម្មវិធី ហើយ **ធីក Auto Confirm User**។
4. ចូល **Authentication → Sign In / Providers** (ឬ Settings) → **បិទ "Allow new users to sign up"**។ ដើម្បីកុំឲ្យអ្នកផ្សេងចុះឈ្មោះបាន។
   (ទោះមិនបិទក៏ដោយ ទិន្នន័យរបស់អ្នកនៅតែមិនអាចមើលឃើញដោយអ្នកដទៃ ព្រោះមានច្បាប់ Row Level Security ក្នុង schema។)
5. ចូល **Project Settings → API** (ឬ API Keys) ចម្លង **Project URL** និង **anon / publishable key**។

> ⚠️ ប្រើតែ key ប្រភេទ **anon / publishable** ប៉ុណ្ណោះ។ **កុំប្រើ `service_role`** ក្នុងកូដ ឬផ្ញើទៅអ្នកណាឲ្យសោះ។

## ខ. ភ្ជាប់កម្មវិធី

បើក `config.js` ហើយជំនួសតម្លៃពីរ៖

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ… ឬ sb_publishable_…'
};
```

សាកល្បងលើកុំព្យូទ័រ៖ ក្នុង VS Code ចុចស្តាំលើ `index.html` → **Open with Live Server** ហើយចូលដោយអ៊ីមែល/លេខសម្ងាត់ក្នុងជំហាន ក.៣។

## គ. ដាក់ឲ្យប្រើលើទូរស័ព្ទ (Vercel)

- ជម្រើសងាយបំផុត៖ ដាក់ folder នេះជា subfolder (ឧ. `attendance/`) ក្នុង project website របស់អ្នក ហើយ push ទៅ GitHub។ អាសយដ្ឋាននឹងជា `…vercel.app/attendance/`។
- ឬបង្កើត repo/project Vercel ថ្មី ដោយដាក់តែ 5 file នេះ។
- លើទូរស័ព្ទ៖ បើក link ក្នុង Safari/Chrome → **Add to Home Screen** ដើម្បីបើកដូច app។

## ឃ. ចាប់ផ្តើមប្រើ

1. ចុច **+** ខាងលើស្តាំ → ជ្រើសថ្ងៃណាមួយក្នុងសប្ដាហ៍ → **បង្កើត** (កាលវិភាគគំរូពី Excel ចាស់ត្រូវបានដាក់ឲ្យរួច)។
2. ផ្ទាំង **សិស្ស** → **នាំចូលពី Excel** → ជ្រើស file Excel ចាស់ ឬ file ថ្មីដែលមានជួរ "ល.រ / ឈ្មោះ / ភេទ / ថ្ងៃកំណើត" ហើយមើលមុនចុច **នាំចូល**។
3. ផ្ទាំង **កាលវិភាគ** → ពិនិត្យ/កែមុខវិជ្ជា ហើយចុច **រក្សាទុក**។
4. ផ្ទាំង **កត់វត្តមាន** → ជ្រើសថ្ងៃ និងម៉ោង → ប៉ះលើស្ថានភាពរបស់សិស្ស៖ **✓ មក → អត់ច្បាប់ → មានច្បាប់ → មក**។
   - **មកទាំងអស់**៖ លុបអវត្តមានទាំងអស់ក្នុងម៉ោងនោះ
   - **ចម្លងពីម៉ោងមុន**៖ សម្រាប់មុខវិជ្ជា ២ ម៉ោង
   - **⋯**៖ កត់ម្នាក់ឲ្យទាំងព្រឹក/រសៀល/ពេញថ្ងៃ ក្នុងម្តង
5. ផ្ទាំង **របាយការណ៍** → អ្នកឈប់ប្រចាំថ្ងៃ · សរុបសប្ដាហ៍ · សរុបខែ → **នាំចេញ Excel**។

| មុខវិជ្ជា និងម៉ោងសិក្សា | ផ្ទាំង **កាលវិភាគ** (កែបានសប្ដាហ៍នីមួយៗ) → "ប្រើជាគំរូ" ដើម្បីឲ្យសប្ដាហ៍ក្រោយៗចម្លងតាម |

| ចំនួនម៉ោងព្រឹក/រសៀល | ផ្ទាំង **ការកំណត់** |

## ច. ចំណាំសំខាន់

- **Backup៖** នាំចេញ Excel រៀងរាល់ខែទុកជាការបម្រុង (គម្រោង Supabase ឥតគិតថ្លៃមាន backup មានកំណត់)។
- **Pause៖** គម្រោងឥតគិតថ្លៃត្រូវបាន pause បើគ្មានសកម្មភាពប្រហែល ១ សប្ដាហ៍ (ឧ. ពេលសាលាឈប់សម្រាកយូរ)។ ចូល dashboard ចុច **Restore** ទើបប្រើបានវិញ។
- **ត្រូវមានអ៊ីនធឺណិត** ពេលកត់។
- **កាលបរិច្ឆេទចន្ទគតិ** (ឧ. "៥រោច ខែជេស្ឋ ឆ្នាំមមី…") មិនត្រូវបានបញ្ចូលដោយស្វ័យប្រវត្តិទេ។ ក្នុង Excel ដែលនាំចេញមានតែកាលបរិច្ឆេទសុរិយគតិ អ្នកអាចវាយបន្ថែមខ្លួនឯង។
- **Excel ដែលនាំចេញ**៖ រក្សារចនាសម្ព័ន្ធដូច file ចាស់ (ជួរចាប់ផ្តើមពីជួរទី ១៥, AN/AO, រូបមន្ត COUNTIF) ប៉ុន្តែពណ៌ក្នុងក្រឡាជាពណ៌ថេរ មិនកែតាមតម្លៃទេ ពេលអ្នកកែក្នុង Excel។
- **លុបសិស្ស = លុបវត្តមានទាំងអស់របស់សិស្សនោះ។** បើគ្រាន់តែឈប់រៀន សូមប្រើ "លាក់" (ដកធីក "នៅរៀន")។
